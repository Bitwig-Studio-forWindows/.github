## 🚀 Key Features

- **The Grid** — Connect modular devices to design synths and audio processing systems.
- **Clip Launcher** — Trigger and arrange musical clips interactively.
- **Hybrid Tracks** — Combine MIDI instruments and recorded audio within one track.
- **Modulators** — Link changing control signals to parameters across devices.
- **Polyphonic Modulation** — Create independent expression and movement for individual notes.
- **MIDI Editing** — Refine notes, expression and velocity within MIDI clips.
